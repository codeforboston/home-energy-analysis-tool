title: Help for Design Temperature Override

markdown: The heating design temperature is the coldest outdoor temperature for which the heating system should be capable of supplying sufficient heat to maintain a desired indoor temperature.  70°F is standard. 

Here are some reasons to override the calculated value by entering a different value in this field, including:

- You want to compare the output from this tool with a Manual J analysis performed for a different design temperature. In this case, enter an override value that matches the heating design temperature used in the Manual J analysis

- You judge that the calculated value is too low or too high.

- A different value specified by the building code for the local jurisdiction (uncommon)

If you do NOT want to override the calculated value, leave this field blank or delete the current value, if any.
